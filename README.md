# KAIJU Anime Platform

Anime platform built with React, Vite, TailwindCSS, and Jikan API.

## Features
- Trending anime and manga
- Search anime and manga
- Anime and manga cards
- Responsive UI

## Technologies
- React
- TailwindCSS
- Vite
- Jikan API
